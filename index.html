Architecture

The production
pipeline

A sklearn Pipeline bundles the StandardScaler and RandomForestRegressor into one atomic object. One file. One call. No data leakage possible.

The pipeline is serialized to production_model.pkl and loaded once at Flask startup. Every POST request receives a scaled, predicted result in milliseconds.

Pipeline object
steps:
  scaler → StandardScaler()
  regressor → RandomForestRegressor()
fit: X_train, y_train
saved: production_model.pkl
01
Load California Housing dataset
fetch_california_housing() → 20,640 samples, 8 features, continuous target in $100k units.
sklearn
02
Train / test split
80% train, 20% test. random_state=42 for reproducibility. 16,512 training samples.
pandas
03
StandardScaler normalization
Fits on training data only. Zero mean, unit variance. Prevents data leakage to test set.
step 1
04
RandomForest training
100 estimators, parallel execution (n_jobs=-1). Bootstrap sampling, feature randomness.
step 2
05
Serialize to .pkl
joblib.dump() writes the complete pipeline — scaler + model — to a single binary file.
joblib
06
Flask REST API
POST /predict receives JSON, pipeline.predict() scales and infers, returns structured JSON.
flask

Integration

Three scripts,
one service

Train locally. Serialize the brain. Serve via HTTP. Any language, any frontend, any cloud.

1
Run train_and_save.py — builds and serializes the full pipeline to production_model.pkl.
2
Run app.py — Flask loads the pkl, exposes /predict and /batch_predict endpoints.

Run test_api.py — fires 5 integration tests including single, batch, and error-handling scenarios.

pipeline = Pipeline([
  ('scaler',
   StandardScaler()),
  ('regressor',
   RandomForestRegressor(
     n_estimators=100,
     random_state=42
   ))
])

pipeline.fit(X_train, y_train)

# Save the brain
joblib.dump(
  pipeline,
  'production_model.pkl'
)
from flask import (
  Flask, request, jsonify
)
import joblib, pandas as pd

app = Flask(__name__)
model = joblib.load(
  'production_model.pkl'
)

@app.route('/predict',
  methods=['POST'])
def predict():
  data = request.get_json()
  df   = pd.DataFrame([data])
  pred = model.predict(df)
  return jsonify({
    'prediction_usd':
      pred[0] * 100_000
  })
